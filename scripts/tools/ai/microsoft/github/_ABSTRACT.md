# GitHub - Copilot

## Platform

* Linux
* Mac
* Windows

## Projects

* Global settings
  * Managed via VSCode `settings.json` under the `github.copilot.*` keys
    (e.g. `github.copilot.enable`, `github.copilot.editor.enableAutoCompletions`).
  * Per-repository instructions: `.github/copilot-instructions.md` at the repository root.
